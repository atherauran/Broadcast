# 老师反馈改进（本地开发分支）

## 行为

- 便签最多 300 个 Unicode 字符，创建和编辑时可选择 18–48 的整数字号。默认 20，与旧版桌面默认大小一致。长内容在卡片内滚动，不截掉文字；超过屏宽的多列也可滚动。
- 值日表采用独立标题和蓝色卡片，普通绿色便签不会误判为值日表。新服务器用 `content.duty=true` 标记；桌面兼容旧服务器的合成值日消息。
- 公告支持独立的 `content.signature`，默认“班主任”，可改为学科老师等，最多 40 个 Unicode 字符。真实发布人仍在 `teacher_name` 中保留，修改署名不改变审计身份。旧公告缺少此字段时桌面仍显示旧发布人，编辑后采用新署名。
- 公告编辑器支持拖动左侧手柄到另一行的手柄或输入框排序，同时提供上移/下移按钮，键盘和触屏无需拖动。草稿、定时发布和多班复制保留顺序与署名。
- “正在显示”中可多选隐藏或恢复显示。隐藏的项目保留原内容、时间和记录，仍列于管理页；恢复不延长有效期，也不重置倒计时。
- 课表/值日编辑器中可分别隐藏课表和值日表。隐藏后仍可编辑保存，恢复后使用保留的内容。

## 发布依赖与兼容

1. 审查并执行迁移 `supabase/migrations/202610200001_teacher_feedback.sql`。
2. 更新教室桌面端以使用字号、独立值日样式和自定义署名。
3. 发布教师端；新增的隐藏列和管理 RPC 依赖上述迁移。

新教师端不能直接连接未迁移的数据库。未更新的旧教室端会接收服务器过滤后的可见列表，因此隐藏仍有效；旧版界面不会显示新字号、值日新样式或新署名。不要仅通过回退网页删除数据库列或迁移函数。

新管理 RPC 与现有管理功能一致，需要管理员验证；设备账号不能更改隐藏状态。图片/数据不在本轮范围。此分支没有执行生产数据库迁移或向真实班级发送测试广播。
