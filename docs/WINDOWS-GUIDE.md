# 教室端使用说明

适用于 Windows 10 22H2 / Windows 11 x64。电脑需要正常登录桌面，并能访问 Supabase 的 HTTPS、WebSocket 以及腾讯云 TTS 地址。

## 首次运行

1. 将压缩包解压到固定目录，例如 `C:\SchoolBroadcast`。程序会从这个位置登录自启，完成绑定后不要随意移动 EXE。
2. 在同目录的 `appsettings.json` 中填写 Supabase 地址、公钥、管理员登录邮箱，以及腾讯云 `SecretId`、`SecretKey`、地域、音色等语音配置。邮箱和云端参数由部署人员预先配置，老师和教室管理员只需输入密码。
3. 双击 `Broadcast.Classroom.exe`。不需要安装 .NET，也不需要以 Windows 管理员身份运行。
4. 输入广播系统的管理员密码，选择这台电脑所属班级，点击“绑定并开始接收”。已被其他电脑绑定的班级不可选。
5. 程序进入托盘，后续随当前 Windows 用户登录自动运行。正常接收无需保持设置窗口打开。

EXE 内包含 .NET 和 Avalonia 所需运行文件，原生运行库（`.dll`）放在 EXE 旁边，启动时不再解压到临时目录。请把压缩包里的全部文件放在同一目录。`appsettings.json` 是可编辑配置文件，不是额外运行时依赖。它包含腾讯云密钥，应限制读取权限，不要发送给无关人员。

## 日常运行

- 收到有效广播后，全屏显示发布老师、可选 emoji 和鲜明颜色的正文，由本机直接调用腾讯云生成并播放语音。
- 语音可设置为 0–4 遍。0 遍只显示文字；多遍播放只合成一份音频，由本机重复播放。
- 选择自动关闭时，正常音频播完后停留 3 秒；选择手动关闭时，界面保留并显示“关闭”按钮。如果后来又有新广播，新广播会先打断这条已播完、正等待关闭的广播；新广播结束（自动或手动关闭）后，这条广播重新显示并继续等待关闭。
- 广播按顺序播放；发送后 30 秒仍未开始的广播直接作废，包括因前一条播放较长而超时的排队广播。
- 语音不可用时仍显示正文，通常自显示起共 10 秒；如果声音在播放一段时间后才失败，正文至少保留至 10 秒，不会撤回已经显示的内容。
- 程序异常退出（崩溃、被结束进程）后会在几秒内自动重启；任务管理器里会看到两个同名进程，其中一个是守护进程。通过托盘“退出广播”退出不会重启。
- 掉线后自动重连。重新上线只处理有效期内且没有开始处理过的广播。
- 锁屏、Windows 登录界面和 UAC 安全桌面不能显示广播；使用时请保持进入正常桌面。程序不自动解除静音或提高系统音量。

## 管理

- 点击托盘图标，或再次双击 EXE，打开“教室设置”。验证管理员密码后可以改绑或解绑。
- 托盘“退出广播”也需要管理员密码。退出仅停止本次运行，下一次登录仍会自动启动。
- 如果旧电脑已损坏，可在老师端右上角“设备管理”解除其绑定，然后在新电脑绑定。
- 配置文件有变更时退出并重新启动。可使用 `appsettings.local.json` 完整覆盖同目录的基础配置。
- 配置尚未填写时关闭设置窗口会退出程序；填写后重新打开即可。

Supabase 设备登录凭据使用当前 Windows 用户的 DPAPI 加密，存放在 `%LOCALAPPDATA%\BroadcastClassroom\device.credential`。该凭据绑定后不再变化，程序每次启动用它登录，因此可以在绑定后开启 DeepFreeze 等还原系统。不要复制此文件到其他账号或电脑。腾讯云凭据保存在程序旁的 `appsettings.json`。故障日志为 `%LOCALAPPDATA%\BroadcastClassroom\client.log`；回执暂存文件不包含管理员密码或腾讯云密钥。

若要卸载，先解绑并退出，然后删除程序目录，并从 Windows“启动应用”禁用 `BroadcastClassroom`。对应自启项位于当前用户注册表 `Software\Microsoft\Windows\CurrentVersion\Run`。

## 文件传输

老师端的“文件传输”独立于广播。选择班级和一个文件后发送，教室端会自动保存到当前 Windows 用户的桌面，不会打开文件或打断广播。同名文件会加上 `(1)`、`(2)` 等编号，不覆盖桌面原文件。每个文件最大 20 MB；离线电脑须在发送后的 24 小时内上线接收。

传输记录会显示等待接收、正在下载、已下载到桌面、下载失败或已过期，并显示实际保存的文件名。失败后可重新选择文件发送。云端文件会在所有目标完成处理或过期后自动删除，桌面上的文件不受影响。开启磁盘还原的电脑重启后，桌面文件仍遵循原有的还原规则。

手动测试：发送一个小文件到测试班级，核对桌面内容及“已下载到桌面”回执；再次发送同名文件，确认原文件保留；断网后发送，24 小时内恢复网络，确认自动接收。接收文件期间也可发送一条广播，确认广播照常工作。

## 义卖实时统计

绑定班级后默认打开“义卖实时统计”。这是普通桌面窗口，可以拖动、调整大小、最小化和关闭，不会置顶。关闭后可从托盘菜单“义卖实时统计”重新打开。

1. 点击“录入筹码 / 查看记录”，输入组长姓名和本次新增的整数筹码，点击“添加收入”。例如填写“张三”，小组自动显示为“张三组”。已有小组可以直接点选。
2. 排行榜、全班总额和收入增长曲线会随保存结果更新。每笔收入及时间保存在云端，重启或更换绑定电脑后仍可查看。
3. 录错时，在收入记录中点击“纠错”，填写正确的组长姓名和数量；填 0 可撤销这笔收入。原记录仍保留，统计以最新纠错结果为准。曲线会按原收入时间重新计算。
4. 网络中断时不会提示保存成功。出现“重试提交”后，恢复网络再点击重试，同一笔不会重复累计。
5. 老师可在“教室设备”中关闭某班的“义卖实时统计”，默认开启。关闭只收起窗口，不清空记录；“隐藏桌面”也会收起统计窗口。

手动测试请使用 Test 班级：输入组长张三 100、李四 50、张三 25，核对显示为“张三组”“李四组”，总额 175；将第一笔纠正为李四 80，核对总额 155、李四组 130；撤销李四组的 50 后核对总额 105。再测试拖动缩放、窗口关闭后从托盘重开、教师开关、断网重试和重启后恢复记录；发送广播时统计同步应照常工作。
